# Blitz (devnads) — Monad ecosystem hub

Site: https://blitz.devnads.com/

Blitz is an **ecosystem / event hub for Monad**, built by the devnads community team. It's a
directory and aggregator rather than a developer API platform.

## What it offers

- **Events** — submit and browse community events / gatherings on Monad testnet.
- **Ecosystem directory** — apps, project showcases, infrastructure providers, and dev tools.
- **Developer resources** — links to Monad docs and building guides.
- **Programs & accelerators** — DeltaV, Monad Momentum, Monad Madness, Mach Accelerator,
  and hackathon opportunities (evm/accathon).
- **Ecosystem links** — MonadVision (explorer), Monadscan, Gmonads, and the research forum.

## Related: the devnads agent APIs

Separately from the Blitz site, devnads hosts agent-friendly APIs used throughout this repo's
build tooling (`https://agents.devnads.com`):

- **Faucet:** `POST /v1/faucet` — fund a testnet address (see [`faucet.md`](./faucet.md)).
- **Verify:** `POST /v1/verify` — verify a contract on all explorers at once
  (see [`deploy-foundry.md`](./deploy-foundry.md)).
